# Emmanuel Ngwoke Portfolio

Single-page portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Lucide.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content

Edit copy, projects, and links in [`src/data/content.ts`](src/data/content.ts). Place your CV PDF at `public/Emmanuel_Ngwoke_CV.pdf`.

## Deploy

Push to GitHub and import the repo in [Vercel](https://vercel.com). Framework preset: Vite.
